# HeartLink ❤️

HeartLink is a dating app project focused on helping people connect, chat, and build meaningful relationships.

## Android project

This repository contains the starter Android application.

### Open in Android Studio
1. Download or clone this repository.
2. Open the `HeartLink` folder in Android Studio.
3. Let Gradle sync.
4. Run the app on an Android phone or emulator.
